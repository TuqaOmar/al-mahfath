# هوية المحفظ — دليل الألوان للواجهة

المصدر: دليل ألوان الشعار (هوية سفر، الصفحة 2.1 «كود ألوان الشعار»). كل الألوان معرّفة كـ CSS variables في `src/index.css` — **استخدميها بدل كتابة hex داخل المكونات.**

## الألوان الأساسية

| الدور | المتغير | فاتح | داكن | من الدليل |
|---|---|---|---|---|
| الأساسي (أزرار، روابط، التحديد) | `--primary` | `#7A4069` بنفسجي | `#B15A92` | R122 G64 B105 |
| نجاح / إنجاز / إجابة صحيحة | `--success` | `#377D71` تركوازي | `#4FA899` | R55 G125 B113 |
| معلومات / روابط ثانوية | `--accent` | `#1F5F7A` | `#4CB8E6` | Navy R22 G56 B73 + تدرّج السماوي |
| ذهبي (سلاسل، أوسمة، تمييز) | `--secondary` | `#9A5F0C` نص · `#E39A2D` زخرفة | `#E39A2D` | شريط الزخرفة الذهبي |
| الخلفية | `--bg-color` | `#F7F5F3` | `#170D15` بنفسجي ليلي | خلفية الدليل / الشريط العلوي |
| النص | `--text-primary` | `#221A22` | `#F7F0F5` | |

ألوان ثابتة للزخرفة والرسوم: `--brand-plum`, `--brand-plum-dark`, `--brand-plum-soft`, `--brand-teal`, `--brand-teal-dark`, `--brand-mint`, `--brand-navy`, `--brand-sky`, `--brand-gold`, `--brand-ink`. ولشفافية مرنة: `rgba(var(--primary-rgb), 0.15)` و`rgba(var(--success-rgb), 0.15)`.

## قواعد
1. **التباين (WCAG AA):** النص العادي ≥ 4.5:1. النص الأبيض على `--primary` الفاتح = 7.6:1، وعلى التركوازي 4.85:1. **لا نص أبيض على الذهبي** (2.35:1) — استخدمي نصًا داكنًا `--brand-ink` فوق الذهبي.
2. **البنفسجي للتفاعل، التركوازي للنتيجة:** زر/رابط/عنصر محدد = بنفسجي؛ تم/صحيح/مكتمل = تركوازي؛ خطأ = `--error` فقط.
3. **الذهبي للتمييز وليس للأزرار:** سلسلة الأيام، الأوسمة، الأرقام المميزة، الزخارف.
4. الأحمر (`#EF4444`, `#DC2626`) يبقى للأخطاء فقط.
5. أي لون جديد يُضاف هنا وفي `src/index.css` أولًا.
